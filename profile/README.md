# Kunko AI Labs

Independent audits for AI systems. We build open-source harnesses that measure what AI benchmarks don't: calibration, honesty, and drift.

## Projects

- **[judge-audit](https://github.com/kunko-ai-labs/judge-audit)** — the Moody's of AI judges. Calibration audits (ECE, reliability diagrams, accuracy-coverage), drift gates, and an MCP server. `pip install kunko-judge-audit`
- **[agent-assurance](https://github.com/kunko-ai-labs/agent-assurance)** — a GitHub Action that checks your AI agents before they ship.
